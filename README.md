# Power BI E-commerce Operations & Customer Insights Dashboard

## Project Overview
This project focuses on logistics optimization and sales performance for "Nexus Goods." I analyzed a large-scale dataset to identify where the business was losing money on shipping and which products were the most successful.

## S.T.A.R. Details
* **Situation:** Required logistics optimization and performance analysis for "Nexus Goods."
* **Task:** Analyzed 100,000+ orders to identify delivery bottlenecks and profit categories.
* **Action:** Integrated 8+ datasets in **Power BI** with data cleaning performed in **Python**.
* **Result:** Visualized shipping lead times and identified the top 5 most profitable categories.

## Key Skills Demonstrated
* **Data Visualization:** Created interactive dashboards in Power BI.
* **Data Cleaning:** Used Power Query and Python to handle 100,000+ rows.
* **Business Intelligence:** Identified shipping bottlenecks to improve delivery speed.
